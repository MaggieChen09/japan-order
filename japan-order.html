從 Google Sheet 匯入

在試算表選取 A～G 欄（可包含分類列、標題列），複製後貼在下方。欄位順序：價格、品名、日文、羅馬拼音、中文諧音、單價、數量。

匯入會取代目前所選餐廳的菜單與份數；這是手動匯入，不會與 Google Sheet 同步。按重計價請在品名保留「每克」字樣，單價填起價。留白的數量視為 0。

旅途中，新增一家餐廳

01 提供菜單 → 02 核對菜名價格 → 03 加入餐廳

貼上公開餐廳菜單網址，或從相簿選一張菜單照片。每次一張，建議拍清楚菜名和價格。

若 iPhone 照片無法讀取，可改上傳螢幕截圖。Google 地圖、需登入或只有圖片的網頁，建議直接截圖。

按下辨識後，照片或該網頁內容會傳送至 OpenAI 辨識服務，會產生 API 用量。核對後才會存入這台裝置。

請逐項確認日文菜名、中文與日圓價格。不清楚的價格請詢問店員，或取消勾選；新增餐點預設為 0 份。
